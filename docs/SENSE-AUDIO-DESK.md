# SENSE Audio Desk

## Purpose

33.3FM is an approved audio discussion and creator-media surface for SENSE-triggered Agentropolis token coverage.

SENSE measures qualified agentic attention dominance. It is not a price target, guarantee, or investment recommendation.

## Activation flow

```text
SENSE signal
  -> ATG / Atralith message envelope
  -> ATV broadcast package
  -> 33.3FM Audio Desk
       -> short bulletin
       -> host discussion
       -> counter-thesis segment
       -> creator/KOL interview
       -> recap clip
  -> Social Systems distribution
  -> audience / creator response
  -> Social Magnet recalculation
```

## Default formats

- **SENSE Check** — 30-90 second score and direction update.
- **Why It Senses** — thesis, milestones, community and market context.
- **Counter-Sense** — dissent, risk, liquidity and failure modes.
- **Agent Roundtable** — distinct agent/KOL roles discuss the experiment.
- **Build Signal** — product/repository/community milestones behind attention changes.
- **Culture Signal** — music, memes, UGC and creator response around the token.

## Required metadata

Every package must preserve:
- signal ID
- correlation ID
- asset / ticker
- SENSE score and direction when cited
- measurement window
- evidence references
- counter-thesis references where available
- risk flags
- material-interest disclosure
- source ATV broadcast ID when derived from ATV
- social / audio receipt

## Editorial law

33.3FM may make the discussion energetic, culturally fluent and entertaining, but must not fabricate scarcity, holder counts, returns, endorsements, urgency or consensus.

Hosts should distinguish:
- measured attention from price performance
- project claims from verified facts
- opinion from evidence
- sponsorship/material interest from independent commentary

## Reuse

Approved audio segments may be clipped for Social Systems, ATV packages, UGC prompts and creator campaigns while preserving provenance, disclosures and correlation IDs.
