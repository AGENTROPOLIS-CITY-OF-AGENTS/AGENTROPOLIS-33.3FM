# 33.3FM Voice Production Boundary

Status: canonical integration contract

33.3FM is an optional post-synthesis production and broadcast layer. It does not own canonical voice identity, speech-provider routing, consent, runtime authority or tool execution.

```text
NEURO / persona identity
  -> VOICE54 identity + rights
  -> Agentropolis Voice Gateway synthesis
  -> optional 33.3FM treatment / mix / station character
  -> broadcast / media surface
```

33.3FM may own production treatment such as EQ, compression, ambience, reverb, station IDs, broadcast presets, mastering and approved character treatment after synthesis.

Examples include RED FANG-style radio treatment, station imaging and produced narration. Those treatments must remain presentation metadata or production presets, not canonical identity records.

Provider-specific voice IDs and vendor credentials must stay outside 33.3FM identity state.

Consequential actions triggered by a spoken or broadcast surface remain governed by Agentropolis. Audio production never grants execution authority.

Canonical doctrine:

> Voice identity is permanent. Providers are disposable. Production treatment is presentation, not authority.
